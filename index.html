install-guide

How to install & launch StudySprint.

Because StudySprint is installed directly via APK, your phone requires a couple of quick permission steps.

01

Download File

Tap "Download App" to save STUDYSPRINT.apk to your phone.

⚠ Seeing a "File may be harmful" warning?

This is a standard system warning for any Android package installed outside the Play Store.

  1. When browser warning appears, select Download anyway.
  2. If blocked on launch, click Settings and turn on Allow from this source.
  3. Complete installation, open StudySprint, and grant storage permissions to enable offline downloads.
02

Open File

Open your file browser or notification tray and tap the APK file.

03

Allow Source

Toggle "Allow from this source" if prompted by Android security settings.

04

Launch & Study

Open StudySprint, pick your university, and start downloading materials.
